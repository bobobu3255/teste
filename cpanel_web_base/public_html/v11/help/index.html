Telegram Pro V11

Central simples para ajuda, catalogo de IA, atualizacoes e logs tecnicos.

IA Local

Para uso offline, instale Ollama ou configure llama.cpp portatil. Modelos recomendados ficam em /v11/ai_models.json.

Logs

O endpoint /v11/api/log.php recebe somente logs tecnicos quando voce ativar uma chave no servidor e no app.

Seguranca

Nao envie senhas, contas, cartoes, tokens ou bancos sem criptografia local.
